# ADR 0059 — Plataforma mínima Android 12 (API 31)

**Status:** Aceito — implementado em 22/11/2026
**Data:** 2026-11-22
**Responsável:** usuário 0 (decisão de plataforma) e implementação
**Documentos de origem:** [`PRD_ARTE_PNG_ROTA.md`](../PRD_ARTE_PNG_ROTA.md), [`ADR 0058`](0058-art-png-route.md), `AGENTS.md`

---

## 1. Contexto

O app tinha `minSdk 26` (Android 8.0), mas o usuário 0 definiu que o alvo real é **Android 12 em diante**. Manter Android 8/9 obriga a feature de Arte PNG a lidar com o modelo de armazenamento antigo:

- `MediaStore.Images.Media.RELATIVE_PATH`/`IS_PENDING` só existem a partir de API 29 (Android 10).
- Em API 26–28, salvar em `Pictures/MeuCoach` exigiria `WRITE_EXTERNAL_STORAGE` e o caminho legado (`DATA`), com fluxo de permissão.
- O `StoryVideoExporter.publishImage` já tinha um branch `< Q` que devolvia `FileProvider` em vez de salvar na galeria; a Arte PNG herdaria essa exceção.

Como o público-alvo não usa Android 8/9 (e o aparelho de referência é o S24 Ultra), sustentar essa faixa adiciona complexidade e testes sem valor de produto.

## 2. Decisão

- **`minSdk` do app e dos módulos Android (`:core:data`, `:core:designsystem`) sobe para 31 (Android 12).**
- O branch de publicação `< Q` do story **é removido**: `StoryVideoExporter.publish` sempre publica no MediaStore; `publishImage` sempre usa `Pictures/MeuCoach`.
- `StoryExportWorker` deixa de declarar `ForegroundInfo` sem tipo de serviço; o app inteiro está em API 31+.
- A Arte PNG usa o mesmo contrato: **Salvar PNG** disponível em todos os aparelhos suportados, sem `WRITE_EXTERNAL_STORAGE` e sem “share-only”.
- `FileProvider` continua no manifesto para outros usos que ainda o exijam, mas a Arte PNG não depende dele para salvar.
- A matriz de testes de aparelho passa a ser **Android 12+**; API 26–28 sai do DoD.

## 3. Alternativas rejeitadas

| Alternativa | Motivo |
|---|---|
| Manter `minSdk 26` e esconder a Arte PNG em < 31 | Mantém complexidade e uma feature “quebrada” para parte dos usuários; o alvo declarado é 12+. |
| Manter `minSdk 26` e adicionar `WRITE_EXTERNAL_STORAGE` em 26–28 | Permissão nova para uma feature de compartilhamento; fluxo e testes desnecessários. |
| `minSdk 29` (Android 10) | Ainda inclui Android 10/11, que o alvo declarado não exige; o ganho de MediaStore já vem em 29, mas o corte de 12+ é a decisão de produto. |
| `minSdk 33` (Android 13) | Corta Android 12/12L sem necessidade. |
| Feature-gate por versão | Duplica caminhos de export/share e o DoD; pior que cortar a faixa. |

## 4. Consequências

### Boas

- Um único caminho de publicação: MediaStore + `Pictures/MeuCoach`.
- Sem permissão de armazenamento e sem branch `< Q` na Arte PNG.
- Menos condicionais e testes de plataforma no story.
- Escopo alinhado ao alvo real (Android 12+).

### Ruins / riscos

- **Corte de usuários:** Android 8, 9, 10 e 11 deixam de ser suportados.
- **Testes:** a matriz de aparelho/emulador muda para API 31+; os testes existentes que usam `@Config(sdk = [35])` continuam válidos.
- **Código legado:** outros guards `< O` (notificações) ficam inalcançáveis, mas não bloqueiam; podem ser limpos em uma tarefa separada.
- **FileProvider:** permanece no manifesto; não é removido neste ADR para não afetar outros fluxos.

## 5. Implementação e aceite

Implementado:

- `app/build.gradle.kts`, `core/data/build.gradle.kts`, `core/designsystem/build.gradle.kts`: `minSdk = 31`.
- `StoryVideoExporter`: removido o branch `< Q` de `publish`/`publishImage`; `savedToGallery` do story passa a ser sempre `true` no caminho real.
- `StoryExportWorker`: `ForegroundInfo` com `FOREGROUND_SERVICE_TYPE_DATA_SYNC` direto.
- Documentação de plataforma (`README`, `AGENTS`, `ARCHITECTURE`, `PRD_COACH`) atualizada para API 31.

Aceite:

- `:app:assembleDebug` e `:app:testDebugUnitTest` verdes.
- `spotlessCheck` verde.
- Nenhum branch `< Q` no caminho de publicação do story.
- Validação em Android 12+ (S24 Ultra) e emulador API 31+.
